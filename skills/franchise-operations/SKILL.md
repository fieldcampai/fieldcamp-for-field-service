# Franchise HQ operations

Read [connected work](../../shared/connected-work.md), [operating rules](../../shared/operating-rules.md), and the [API map](../../docs/connected-apis.md). Distinguish franchise ID, operational node ID, workspace ID and HQ member ID. Confirm the actual authorized reporting and management scope.

1. Identify the requested outcome. For branch routing, inspect territory, active operational branch and assignment policy. For standards, inspect the current version and classify affected branches. For reporting, use [analytics API review](../analytics-api-review/SKILL.md). For department deployment, use [department rollout](../department-rollout/SKILL.md).
2. For incoming leads, verify source ID, territory/channel, service department, chosen branch and assignment receipt. Hold unrouted leads for HQ triage when coverage overlaps or is unknown. For a next action, preview the newly responsible branch before changing anything. Retain the original evidence and request/job reference.
3. For standards, separate edit draft, publish version, push to chosen branches and remediate drift. Report deviations, exceptions and locks. Review a canary branch and preserve the prior version or restore reference. Roles/invitations, shared staff, add-on governance, royalties and pricing changes go to the authorized HQ process when dedicated tools are absent.
4. For a network digest, verify that the module is enabled and the current deployment offers the relevant template. Confirm network-wide workflow permissions, selected operational nodes, schedule/timezone, recipient membership IDs, and metric/window. Use the [network digest recipe](../../docs/automation-recipes.md). A branch workflow and HQ network workflow have different scopes and rollout mechanics.
5. Apply only the explicitly approved change through a verified scoped tool. Otherwise prepare an HQ handoff with console location, current state, exact desired state, scope, reviewer, and rollback. Read audit/run receipts when available. For partial results, report each branch independently.
