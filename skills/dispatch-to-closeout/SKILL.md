# Dispatch to closeout

Read [workflow execution](../../shared/run-a-workflow.md), [operating rules](../../shared/operating-rules.md), and [handoffs](../../shared/handoffs.md). Confirm the branch, service day and timezone.

1. **Review the day.** Use [dispatch](../dispatch-day/SKILL.md) to list unassigned work, commitments, gaps and required qualifications. For an urgent insertion use [urgent slot](../emergency-slot/SKILL.md). Check field and customer impact before changing an existing assignment.
2. **Plan stops.** Apply [route planning](../plan-routes/SKILL.md) only when the relevant route tools are actually available. Preserve fixed windows and locks. Without the optimizer, report assignment and schedule checks, and send route changes to the dispatcher for review in FieldCamp.
3. **Confirm approved assignments.** Re-read each visit and recheck the schedule. Verify the resulting assignment and time. If the operator requests customer communication, prepare the specific message and follow [Customer Inbox](../customer-inbox/SKILL.md).
4. **Track what happened in the field.** Use [field visit](../field-visit/SKILL.md) for supported status changes. Qualify ETAs and never infer arrival, attendance, client signature or the technician's physical location from the calendar.
5. **Check the closeout packet.** Apply [forms and documentation](../field-forms-and-documentation/SKILL.md). Compare actual parts, labor and work performed with approved scope. Use [change orders and callbacks](../change-orders-and-callbacks/SKILL.md) for discrepancies.
6. **Release to the next owner.** When visit completion is confirmed, show which jobs have all visits complete, which need billing, and which need customer/technician follow-up. Add or change a task only through [follow-ups](../follow-ups/SKILL.md).

Report selected visits, verified assignments/status, open forms or parts, and the next owner for each exception. Pause closeout if required evidence is missing.
