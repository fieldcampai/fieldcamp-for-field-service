# Prepare a client brief

Read [operating rules](../../shared/operating-rules.md). This workflow is read-only.

1. Resolve a unique client and site with `search` and `get_client_by_id`. Ask which match to use before exposing sensitive details across possible clients.
2. Read the specific job and recent applicable history, upcoming visit, open tasks, and relevant estimate or invoice records via targeted tools. Read payment history only when it is pertinent to the call.
3. Return a short brief with the reason for calling if given, upcoming service, open commitments, billing status if relevant, and what to clarify. Cite FieldCamp IDs and omit sensitive fields that do not matter. Distinguish empty results from unavailable sources.
